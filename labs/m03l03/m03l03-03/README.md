## Goal

You can read a route table, identify its local route, and explain how an internet gateway changes reachability.

In the lesson: The command line interface can inspect route tables without changing them. This transcript shows the local destination and the default destination with their targets. Your account will have different identifiers, and it may have several tables, so filter by the table or subnet you are investigating. When a connection fails, start here before blaming the application. If the destination has no matching route, the packet never reaches a security group. If it has a route, continue to the next control and ask whether that control allows the port and protocol.
