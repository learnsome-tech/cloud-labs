# m07l03-02 · Ask the CLI for identity and region

## Goal

You can choose the console or CLI for discovery and operation while keeping repeatable actions reviewable.

In the lesson: A short shell session answers two questions before an operation. The first command asks which identity the shell is using, and the transcript masks the account number. The second asks for the configured region. Check both before reading or changing a resource, because a familiar command pointed at the wrong account or region can produce a confident and dangerous answer. The console shows the same context in its account menu and region selector, but the command line interface puts it in a transcript that another engineer can inspect.
