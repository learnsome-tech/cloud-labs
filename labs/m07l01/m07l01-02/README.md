## Goal

You can assign cloud ownership with tags, distinguish a budget alert from a spending limit, and build a cost review that connects usage to a responsible team.

In the lesson: Choose tags by the questions a cost review will ask. Name helps a human recognise the resource. Owner and cost centre answer who is accountable for the charge. Environment separates production from development and experiments. Managed by shows whether a console change will be overwritten by automation. Keep values controlled enough to group consistently; finance platform and Finance Platform are two buckets in a report if nobody defines the spelling. A short tag dictionary prevents a long cleanup project later.
