# Exercises — Cost, Budgets, and Tagging

Lesson `m07l01` · [Watch](https://learnsome.tech/courses/cloud-course/watch?lesson=m07l01)

## Exercise 1: Design a cost ownership check

1. Choose five tags that let your team explain every charge.
2. Define the allowed values for environment and ownership fields.
3. Set a budget threshold and name the people who receive alerts.
4. Fail a sample deployment when a required tag is missing.

> **Hint**: Start with the question a finance review asks when a charge has no obvious owner.
