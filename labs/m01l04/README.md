## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Pick a region on purpose

1. List the zones and zone ids for the region nearest your users.
2. Compare the small server price in that region with the same server in Ireland.
3. Write one sentence justifying a region choice on law, latency, price and services.

> **Hint:** The pricing query from the first lesson needs only its location filter changed.

## Check yourself

- Name the four criteria for choosing a region, and say which one can veto the others.
- What physically distinguishes one availability zone from another in the same region?
- Why does AWS shuffle zone letters between accounts, and what should you exchange instead?
- Why does surviving maintenance argue for three zones rather than two?
- Which network paths are free, which are charged, and which is the most expensive?
