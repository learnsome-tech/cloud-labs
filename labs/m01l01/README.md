# m01l01 · Capital to Operating Expenditure

Module 1: The Cloud Proposition · lesson 1.1 · Free · [Open the lesson](https://learnsome.tech/learn/cloud-course/m01l01)

**Goal:** You can explain what changes when a server stops being something you buy and becomes something you rent by the hour, read a real on-demand price out of the AWS pricing API, and say which costs the change removes and which ones it quietly adds.

## Exercises

Open exercises from the lesson, to try on your own. They have no answer files: work them out, and use the labs above as reference.

### Price something you would actually run

1. Change the instance type filter to m5.large and run the price query again.
2. Change the location filter to EU (Ireland) and compare the two numbers.
3. Work out what that instance costs for a nine to five weekday month.

> **Hint:** A weekday working month is about one hundred and ninety hours, not seven hundred and thirty.

## Check yourself

- In one sentence each, what is capital expenditure and what is operating expenditure?
- Why does the pricing query have to name a region, an operating system and a tenancy before it can answer?
- Which risk does renting by the hour remove, and which new risk does it introduce?
- A commitment discount lowers the hourly price for a one or three year promise. Which of the two spending styles does that resemble?
- Why is a forgotten cloud server more expensive than a forgotten physical one?
