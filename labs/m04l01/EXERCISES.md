# Exercises — Elastic Compute Cloud (EC2)

Lesson `m04l01` · [Watch](https://learnsome.tech/courses/cloud-course/watch?lesson=m04l01)

## Exercise 1: Plan one worker

1. Choose a small instance type and image for a worker.
2. Place it in a private subnet and name its role.
3. Write what data survives a stop and what must survive termination.

> **Hint**: Keep the exercise bill free by writing the contract and inspecting existing machines.
