### Plan one worker

1. Choose a small instance type and image for a worker.
2. Place it in a private subnet and name its role.
3. Write what data survives a stop and what must survive termination.

> **Hint:** Keep the exercise bill free by writing the contract and inspecting existing machines.

## Check yourself

- What does an image provide, and what does an instance type provide?
- Why should a workload receive a role instead of a permanent key?
- What differs between stopping and terminating?
- Why is an image not a backup?
- Which command inspects existing instances?
