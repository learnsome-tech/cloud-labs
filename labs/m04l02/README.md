### Choose a container platform

1. Describe one workload as an image, task or pod, and service.
2. List the health check that proves a user request can succeed.
3. Choose ECS or EKS and name the operational feature that drives the choice.

> **Hint:** Keep the decision tied to an actual platform requirement rather than familiarity.

## Check yourself

- What is the difference between an image, a task or pod, and a service?
- What operational surface does managed Kubernetes add?
- Why does a process health check differ from a service health check?
- What should you record for a safe container rollback?
- Which command lists active ECS task definition revisions?
